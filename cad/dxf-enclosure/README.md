# Electronics enclosure — DXF

`basic-box-120x150x100-3mm.dxf` — laser-cutting file for the ClayBreeze electronics enclosure, which will house the ESP32, the relay module and the DHT11 wiring. The file is kept exactly as created.

- Units: millimetres (`$INSUNITS` = 4); 432 `LINE` entities on layer `0`.
- 6 closed, finger-jointed panels, nested on a 426 × 253 mm area:
  - 2 × 120 × 150 mm (top and bottom)
  - 2 × 150 × 100 mm (long sides)
  - 2 × 120 × 100 mm (short sides)
- Box: 120 × 150 × 100 mm. Material: 3 mm MDF (from the file names).
- Status: laser cutting in progress. Photograph: `media/Laser Cutting for project/`.

Panel names are by size only; cable and sensor cut-outs are not yet decided.
