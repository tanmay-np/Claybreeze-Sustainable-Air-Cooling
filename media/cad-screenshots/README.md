These show the design concept, not confirmed as-built measurements of the fabricated frame — see `docs/design-and-dimensions.md` Section 3 for what's still outstanding. Note the rod part is named `20mm_rod` in the CAD tree despite being dimensioned at ⌀12 mm on the drawing — a naming discrepancy, not a dimension conflict — ⌀12 mm matches the physical rods (see `docs/design-and-dimensions.md`).
